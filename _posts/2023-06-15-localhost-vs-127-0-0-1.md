"localhost" is typically resolved into "127.0.0.1". However, some services or applications might try using a Unix domain socket when connecting to "localhost", but using "127.0.0.1" will connect directly to a TCP/IP socket.

This is why example below using "localhost" would fail, but using "127.0.0.1" would succeed.

```
# in docker-compose.yml
...
main-db:
	image: mysql:5.7
	environment:
		MYSQL_ROOT_PASSWORD: '********'
		MYSQL_DATABASE: 'mydb'
	ports:
		- 33061:3306
```

Fails when connected through "localhost".

```bash
mysql -hlocalhost -P33061 -uroot -p******** mydb

mysql: [Warning] Using a password on the command line interface can be insecure.
ERROR 1698 (28000): Access denied for user 'root'@'localhost'
```

Success when connected through "127.0.0.1".

```bash
mysql -h127.0.0.1 -P 33061 -uroot -p******** mydb
Welcome to the MySQL monitor.  Commands end with ; or \g.
...
```
