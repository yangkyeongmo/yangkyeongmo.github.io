"localhost"는 보통 "127.0.0.1"로 해석됩니다. 하지만 어떤 서비스나 애플리케이션은 "localhost"에 연결할 때 Unix 도메인 소켓을 쓰려 할 수 있고, "127.0.0.1"을 쓰면 TCP/IP 소켓에 바로 연결합니다.

그래서 아래 예시는 "localhost"를 쓰면 실패하고, "127.0.0.1"을 쓰면 성공합니다.

```
# in docker-compose.yml
...
main-db:
	image: mysql:5.7
	environment:
		MYSQL_ROOT_PASSWORD: '********'
		MYSQL_DATABASE: 'mydb'
	ports:
		- 33061:3306
```

"localhost"로 연결하면 실패합니다.

```bash
mysql -hlocalhost -P33061 -uroot -p******** mydb

mysql: [Warning] Using a password on the command line interface can be insecure.
ERROR 1698 (28000): Access denied for user 'root'@'localhost'
```

"127.0.0.1"로 연결하면 성공합니다.

```bash
mysql -h127.0.0.1 -P 33061 -uroot -p******** mydb
Welcome to the MySQL monitor.  Commands end with ; or \g.
...
```
